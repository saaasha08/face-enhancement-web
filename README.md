# Face Image Enhancement for Recognition Systems

A professional full-stack web application that enhances facial image quality for face recognition systems under low lighting, blur, and noisy conditions.

## Features

- **5 Professional Enhancement Outputs:**
  1. **Illumination Normalization** - Histogram Equalization + CLAHE
  2. **Gaussian Filtering** - Smooth noise reduction
  3. **Bilateral Filtering** - Edge-preserving denoising
  4. **Edge Enhancement** - Laplacian sharpening + Unsharp masking
  5. **Final Recognition-Ready Image** - Complete pipeline optimized for face recognition

- **Modern Web Interface:**
  - Drag & drop image upload
  - Responsive dark theme design
  - Loading animations
  - Professional dashboard layout
  - Download final enhanced image

- **Technical Stack:**
  - Backend: Flask (Python)
  - Image Processing: OpenCV, NumPy
  - Frontend: HTML5, CSS3, JavaScript
